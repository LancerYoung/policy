A. 功能与设置使用 FAQ

如何启用键盘？

前往 设置 → 通用 → 键盘 → 键盘 → 添加新键盘，选择「嘎嘎」，按提示完成添加。在任意可输入界面点击地球仪 🌐 图标即可切换到本键盘。首次使用无需任何权限，也无需开启"允许完全访问"。

支持哪些输入方式？

  • 五笔画输入：按汉字书写顺序输入横、竖、撇、捺、折五种基本笔画，不认识拼音也能打字。
  • 词格整句：多段输入经词格解码与逐字语言模型排序，长词、词组联想更准更顺。
  • 分词键：手动切分词组边界，帮助引擎更准确地成词（免费）。
  • 上滑输入：标点键上滑弹出符号面板，表情键上滑弹出常用 emoji，手指不离开键盘。

大字模式是什么？免费

专为长辈与视力不佳的用户设计。开启后第一个候选字会以大字号显示在键盘左上角，看得清、点得准；问号等不常用键会隐藏，把空间让给候选。老人、父母也能轻松上手。

键盘外观自定义免费

在主 App 设置里，可对字母键、数字键、功能键分别调整字号、字重、圆角与字体，并控制表情键的显示。改完键盘下次输入时生效。

内置哪些词库？

  • 自研本地笔画词典，覆盖日常与专业用语，纯离线运行。
  • 字频学习与个人词条，随你越用越准。
  • 词格整句语言模型，长句分词与候选排序更聪明。

如何管理学习词库 / 剪贴板历史？

本键盘会学习你的选字习惯以优化候选排序，所有学习数据仅保存在本机（App Group 容器内）。如需清空，请在主 App 设置中找到对应的一键清空项操作，不会影响系统内置词库。剪贴板历史（会员）同样可在设置中一键清空。

皮肤与外观

  • 经典皮肤免费；彩虹渐变、霓虹、赛博、星夜、奶黄、Q弹等进阶 / 高级皮肤需会员。
  • 更换皮肤后所有按键同步变色，所见即所得，并跟随系统亮 / 暗模式。

iCloud 用户词同步免费

开启后，常打的字词会通过你自己的 iCloud 在你的设备间同步，换机登录同一 Apple ID 即找回。数据存储在你自己的 iCloud 私有空间，我们不运营服务器、也无法读取。键盘扩展本身不联网。

A. Features & Setup FAQ

How do I enable the keyboard?

Go to Settings → General → Keyboard → Keyboards → Add New Keyboard, select "嘎嘎 / Gaga", and follow the prompts. Tap the 🌐 (globe) icon in any text field to switch to this keyboard. No permissions are required on first use, and "Allow Full Access" is not needed.

What input methods are supported?

  • Five-stroke input: type the five basic strokes — horizontal, vertical, left-falling, dot, turning — in writing order, so you can type without knowing Pinyin.
  • Lattice-based sentence input: multi-segment input is decoded through a word lattice and character-level language model for longer, smarter phrases.
  • Segment key: manually split phrase boundaries to help the engine form words more accurately (free).
  • Swipe-up input: swipe up on the punctuation key for symbols, or the emoji key for common emojis — without leaving the keyboard.

What is large-text mode?Free

Designed for elders and low-vision users. When enabled, the top candidate appears at a larger size in the top-left of the keyboard — easier to read and tap; less-used keys such as "?" are hidden to give candidates more room. It makes typing approachable even for parents and grandparents.

Appearance controlFree

In the main app's settings you can adjust font size, weight, corner radius, and typeface for letter, number, and function keys separately, and control whether the emoji key is shown. Changes apply to the keyboard's next appearance.

What dictionaries are built in?

  • A self-built local stroke dictionary covering everyday and professional usage, running fully offline.
  • Word-frequency learning and personal entries that improve as you type.
  • A lattice-based language model for smarter segmentation and candidate ranking.

How do I manage the learning dictionary / clipboard history?

The keyboard learns your choices to improve candidate ranking; all learning data stays on your device (in the App Group container). To clear it, use the one-tap option in the main app's settings — it does not affect the built-in system dictionaries. Clipboard history (members) can likewise be cleared in one tap.

Themes & appearance

  • Classic themes are free; Rainbow, Neon, Cyber, Starry, Cream, Bouncy and other advanced/premium themes require membership.
  • All keys recolor together when you switch themes, and it follows the system Light / Dark mode.

iCloud word syncFree

When enabled, the words you use most sync between your devices through your own iCloud — sign in with the same Apple ID on a new device and they're back. The data lives in your own iCloud private space; we run no servers and cannot read it. The keyboard extension itself never connects to the network.

D. 故障排查

键盘不显示 / 候选为空

  • 确认已在 设置 → 通用 → 键盘 → 键盘 中添加并开启「嘎嘎」。
  • 在输入界面点击地球仪 🌐 图标，确认已切换到本键盘。
  • 「允许完全访问」为可选，关闭状态下所有输入功能均正常。

为什么「无法联网 / 候选不更新」？

这是正常现象。键盘扩展默认处于系统离线隔离状态，所有输入与候选均在本地完成；联网仅发生在你主动打开购买页面时。无需担心，也不是故障。

会员 / 订阅不生效

  • 打开主 App，点击「恢复已购项目」重新同步。
  • 确认当前 Apple ID 与购买时一致。
  • 尝试重启设备，或在设置中移除并重新添加键盘。

学习词库异常 / 候选变差

在主 App 设置中清空学习数据即可恢复初始状态（不会删除系统内置词库）。

剪贴板历史 / 进阶皮肤不可用？

剪贴板历史与进阶 / 高级皮肤为会员功能。请确认会员状态有效；若刚购买，可用「恢复已购项目」刷新。

iCloud 词同步没有生效

  • 确认已在系统设置中登录 iCloud，且为嘎嘎开启了 iCloud 权限。
  • 同步需要时间，且要求各设备登录同一 Apple ID。
  • 键盘扩展不联网，同步由主 App 在联网时完成，打开一次主 App 有助于触发。

免费试用 / 体验被重置？

体验起点记录在 iOS Keychain 中以防重装滥用，因此重装应用后体验计时可能重新计算。如已付费，请使用「恢复已购项目」同步会员状态。

D. Troubleshooting

The keyboard doesn't appear / candidates are empty

  • Make sure "嘎嘎 / Gaga" has been added and enabled under Settings → General → Keyboard → Keyboards.
  • In a text field, tap the 🌐 (globe) icon to confirm you've switched to this keyboard.
  • "Allow Full Access" is optional; all input features work normally with it off.

Why "can't connect to the network / candidates don't update"?

This is normal. The keyboard extension is offline by default under iOS sandbox isolation; all input and candidates are processed locally. The network is only used when you proactively open the purchase page. There is nothing wrong, and no need to worry.

Membership / subscription not working

  • Open the main app and tap "Restore Purchases" to re-sync.
  • Confirm the current Apple ID matches the one used for purchase.
  • Try restarting the device, or remove and re-add the keyboard in Settings.

Learning dictionary abnormal / worse candidates

Clear the learning data in the main app's settings to return to the initial state (the built-in system dictionaries are not deleted).

Clipboard history / premium themes unavailable?

Clipboard history and advanced/premium themes are member features. Please confirm your membership is active; if you just purchased, tap "Restore Purchases" to refresh.

iCloud word sync isn't working

  • Make sure you're signed in to iCloud in system settings and iCloud is enabled for Gaga.
  • Sync takes time and requires all devices to be signed in with the same Apple ID.
  • The keyboard extension is offline, so syncing is performed by the main app when online — opening the main app once helps trigger it.

Trial / experience reset after reinstall?

The trial start time is stored in iOS Keychain to prevent abuse via reinstalling, so the trial timer may restart after reinstalling the app. If you've already paid, use "Restore Purchases" to sync your membership status.
