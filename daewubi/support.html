A. 功能与设置使用 FAQ

如何启用键盘？

前往 设置 → 通用 → 键盘 → 键盘 → 添加新键盘，选择「大鹅五笔输入法」，按提示完成添加。在任意可输入界面点击地球仪 🌐 图标即可切换到本键盘。首次使用无需任何特殊授权，也无需开启"允许完全访问"。

支持哪些输入方式？

  • 五笔字型：标准 QWERTY 全键盘，支持全码、一级/二级简码、词组与联想。
  • 智能整句：内置离线语言模型，输入长句时自动整句成词，重码更少、输入更流畅。
  • 五笔智能引导：打字时自动高亮合法后继字母、半透明淡化非法字母，新手也能快速定位下一键。

内置哪些词库？

  • 自研本地五笔词典，覆盖日常与专业用语，纯离线运行。
  • 用户词频学习与个人词条，随你越用越准。
  • 智能整句语言模型，长句分词与候选排序更聪明。

如何管理用户词库 / 记忆？

本键盘会学习你的选词习惯以优化候选排序，所有学习数据仅保存在本机（App Group 容器内）。如需清空，请在主 App「设置 → 重置用户词库」中操作，一键清除全部个人学习数据，不影响系统内置词库。

主题与外观

  • 内置 19 套键盘皮肤：青、暗夜、蓝调（免费）；樱花、海洋、森野、液态玻璃等（Pro）。
  • 更换皮肤所有按键同步变色，所见即所得，并跟随系统亮 / 暗模式。

滑动输入与上滑弹窗

  • 滑动输入：全键盘支持滑动连续输入、数字字母双标签。
  • 上滑弹窗：长按字母上滑弹出标点或表情面板，18 格网格布局，常用符号与表情一键触达。

候选字与触感

  • 候选字大小：可在设置中自由调节（约 14–24pt），适配不同屏幕与视力习惯。
  • 触感反馈：提供关闭 / 轻 / 中 / 重 多档，系统级键盘触感，无需完全访问权限。

A. Features & Setup FAQ

How do I enable the keyboard?

Go to Settings → General → Keyboard → Keyboards → Add New Keyboard, select "大鹅五笔输入法 / Daewubi Wubi", and follow the prompts. Tap the 🌐 (globe) icon in any text field to switch to this keyboard. No special permission is required on first use, and "Allow Full Access" is not needed.

What input methods are supported?

  • Wubi input: standard QWERTY layout with full codes, level-1/level-2 short codes, phrases, and associative prediction.
  • Sentence-level input: a built-in on-device language model automatically forms whole sentences as you type — fewer duplicates, smoother input.
  • Wubi smart guide: automatically highlights legal successor letters and dims illegal ones, helping beginners find the next key quickly.

What dictionaries are built in?

  • A self-built local Wubi dictionary covering everyday and professional usage, running fully offline.
  • User word-frequency learning and personal entries that improve as you type.
  • A sentence-level language model for smarter segmentation and candidate ranking.

How do I manage the user dictionary / memory?

The keyboard learns your word choices to improve candidate ranking; all learning data stays on your device (in the App Group container). To clear it, open the main app and go to Settings → Reset User Dictionary to wipe all personal learning data in one tap — it does not affect the built-in system dictionaries.

Theme & appearance

  • 19 keyboard themes: Cyan, Dark, Blue (free); Sakura, Ocean, Forest, Liquid Glass and more (Pro).
  • All keys recolor together when you switch themes, and it follows the system Light / Dark mode.

Slide input & swipe-up popups

  • Slide input: the full keyboard supports continuous slide input with dual number/letter labels.
  • Swipe-up popups: long-press a letter and swipe up to open a punctuation or emoji panel — an 18-cell grid for quick access to common symbols and emojis.

Candidates & haptics

  • Candidate font size: freely adjustable (about 14–24pt) in Settings to suit different screens and vision needs.
  • Haptic feedback: Off / Light / Medium / Heavy tiers, using system keyboard haptics — no Full Access required.

D. 故障排查

键盘不显示 / 候选为空

  • 确认已在 设置 → 通用 → 键盘 → 键盘 中添加并开启「大鹅五笔输入法」。
  • 在输入界面点击地球仪 🌐 图标，确认已切换到本键盘。
  • 「允许完全访问」为可选功能，关闭状态下所有输入功能均正常。

为什么「无法联网 / 候选不更新」？

这是正常现象。键盘扩展默认处于系统离线隔离状态，所有输入与候选均在本地完成；联网仅发生在你主动打开购买页面时。无需担心，也不是故障。

会员 / 订阅不生效

  • 打开主 App，点击「恢复购买」重新同步。
  • 确认当前 Apple ID 与购买时一致。
  • 尝试重启设备或在设置中移除并重新添加键盘。

用户词库异常 / 候选变差

在「设置 → 重置用户词库」中清空学习数据即可恢复初始状态（不会删除系统内置词库）。

免费试用 / 体验被重置？

体验起点记录在 iOS Keychain 中以防重装滥用，因此重装应用后体验计时可能重新计算。如已付费，请使用「恢复购买」同步会员状态。

D. Troubleshooting

The keyboard doesn't appear / candidates are empty

  • Make sure "大鹅五笔输入法 / Daewubi Wubi" has been added and enabled under Settings → General → Keyboard → Keyboards.
  • In a text field, tap the 🌐 (globe) icon to confirm you've switched to this keyboard.
  • "Allow Full Access" is optional; all input features work normally with it off.

Why "can't connect to the network / candidates don't update"?

This is normal. The keyboard extension is offline by default under iOS sandbox isolation; all input and candidates are processed locally. The network is only used when you proactively open the purchase page. There is nothing wrong, and no need to worry.

Membership / subscription not working

  • Open the main app and tap "Restore Purchases" to re-sync.
  • Confirm the current Apple ID matches the one used for purchase.
  • Try restarting the device, or remove and re-add the keyboard in Settings.

User dictionary abnormal / worse candidates

Go to "Settings → Reset User Dictionary" to clear learning data and return to the initial state (the built-in system dictionaries are not deleted).

Trial / experience reset after reinstall?

The trial start time is stored in iOS Keychain to prevent abuse via reinstalling, so the trial timer may restart after reinstalling the app. If you've already paid, use "Restore Purchases" to sync your membership status.
